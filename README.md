# Glass Prime

Site de vidraçaria com apresentação de serviços e trabalhos.

## Recursos

Seções institucionais, galeria de trabalhos e chamada para orçamento.

## Tecnologias

HTML, CSS e JavaScript; sem etapa de build npm na estrutura analisada.

## Executar localmente

Sirva os arquivos por HTTP; uma opção com Python 3 instalado:

```sh
git clone https://github.com/Felipegaldinos/vidracaria.git
cd vidracaria
python -m http.server 8000
```

Abra http://localhost:8000. Recursos de terceiros, quando usados, exigem conexão com a internet.

## Onde começar no código

- `index.html` — ponto de entrada para entender o projeto.

## Estado atual

Revise dados e canais de orçamento antes de usar com clientes. O site de apresentação não equivale a um sistema de gestão de pedidos.
